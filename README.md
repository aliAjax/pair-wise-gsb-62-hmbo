# 矿山尾矿库监测计划与异常处置审阅平台

基于Angular、Angular Material、NgRx、Angular Router、RxJS、HttpClient、MapLibre GL、Turf.js、Nx和TypeScript的独立前端工程。无后端时自动使用本地模拟数据，界面内操作保留版本和审计。

## 功能

- 位移、水位、渗流、降雨监测点，MapLibre测点图层和Turf巡检路线长度。
- 报警值、变化速率与阈值版本查看。
- 分区监测计划草拟与负责人发布，按分区独立编号；已发布版本永不被覆盖。
- 同一分区两人先后发布时，晚到发布被乐观并发拦截并提示版本冲突，重新确认后在先发布版本之上另出新版本（不覆盖）。
- 异常进入现场复核时冻结当时的监测类型、频率与处置版本（计划快照），后续复测、审批与关闭均认冻结版。
- 升级前已打开但无快照的异常，首次打开时按当时最新已发布版本补齐并标注“升级补齐”；升级前已关闭记录保持原样、不再补齐或改写。
- 异常队列、现场复核、复测、证据、专业异议、处置方案、重大异常应急联动、负责人审批和关闭条件校验。
- 已关闭异常只读，任何处置动作均被拒绝。
- 原始读数只读，所有修订形成独立版本和审计时间线。
- 界面与JSON审阅包包含“计划版本—原始读数—异常状态—审计时间”对应关系。

端口为`18462`。

```bash
npm install
npm run build
npm run dev
```
